<objective>
Wire the **BullMQ worker** to: **GetObject** `manual.pdf` by `s3Key`, read **`CLAUDE_MAX_PDF_PAGES`** from env (parse with `Number.parseInt`, fail job if invalid), run **page preflight**, call **`extractSceneFromPdfBuffer`**, **`PutObject`** pretty-printed JSON to **`uploads/{jobId}/scene.json`** (same prefix as manual key), and mark BullMQ job **completed** with **returnvalue** `{ sceneKey: string }` (exact key string). On failure, use **`job.moveToFailed`** or throw with **`failedReason`** message: for preflight use **`PDF exceeds maximum page limit`** (user-visible); for extraction failures use **`Extraction failed`** or include **`Zod validation failed`** substring only if user-safe — **prefer generic `Extraction failed`** after retries exhausted.

Extend **GET `/api/jobs/[id]`** JSON to include optional **`sceneKey: string | null`** (null unless completed and returnvalue present). Do **not** expose `ANTHROPIC_API_KEY`.

Purpose: End-to-end Phase 2 demo path and API observability for UAT.
</objective>
