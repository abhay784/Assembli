<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → GET `/api/jobs/[id]` | Job id is client-supplied; response leaks only S3 **keys**, not bucket secrets |
| Worker → filesystem | Render reads local audio paths that must stay inside a controlled work directory |
| Worker → S3 | Video bytes written to job-scoped keys only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-12 | Information disclosure | Job status API | mitigate | Return only `videoKey` string (like `sceneKey`); never presigned URLs or raw env in JSON |
| T-3-13 | Tampering | Local path → ffmpeg | mitigate | `assertPathsContainedInDir(audioFiles, workDir)` after `path.resolve` on each path; reject if any path escapes `workDir` |
| T-3-14 | Denial of service | Pipeline | mitigate | Reuse Phase 2 PDF guards; on render failure, fail job with trimmed error message (no full stack to client); delete temp workDir in `finally` |
| T-3-15 | Spoofing | BullMQ returnvalue | accept | Redis is trusted infra for v1 POC; API only reads job owned by queue — document trust assumption |
</threat_model>
