<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SceneJSON → narration text | Step `title`/`caption` are untrusted strings from LLM output |
| Worker → S3 PutObject | Audio objects stored under job-scoped keys |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-04 | Injection | S3 object key | mitigate | Construct keys only from `jobId` validated as UUID-like (alphanumeric + hyphen) and zero-padded numeric index; never interpolate raw step text into keys |
| T-3-05 | Spoofing | ElevenLabs | transfer | HTTPS to official API; API key from env |
| T-3-06 | Denial of service | TTS loop | mitigate | Keep sequential calls per job (per RESEARCH); enforce same max narration length as client wrapper; catch 429 and fail job with readable error (optional single retry with backoff — if added, cap at 1 retry) |
| T-3-07 | Elevation | file paths | mitigate | Write temp audio files under `os.tmpdir()` with `fs.mkdtemp` per job prefix; no user-controlled path segments |
</threat_model>
