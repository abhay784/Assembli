<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Worker filesystem → Remotion `Audio` | Local paths must point only to worker-controlled temp/output files |
| `RenderInput` props | Untrusted relative to code: comes from worker-built arrays after S3/TTS — still validate with Zod before `renderMedia` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-08 | Tampering | `audioFiles` paths | mitigate | Zod only checks non-empty strings + array length parity; **worker** (plan 03-04) resolves a single `workDir` via `fs.mkdtemp` and must pass only files created inside that directory into `RenderInput` — add `assertPathsContainedInDir(paths, workDir)` before `renderAssemblyToMp4` |
| T-3-09 | Denial of service | `durationsInFrames` | mitigate | Zod: cap each duration at e.g. `9000` frames (~5 min at 30fps) and cap `steps.length` at `200`; reject if sum overflows safe integer |
| T-3-10 | Information disclosure | render logs | mitigate | Do not log full `inputProps` or file paths beyond basename in production code; log job id + composition id only |
| T-3-11 | Elevation | ffmpeg binary | transfer | Use pinned `ffmpeg-static` dependency; no download of remote binaries at runtime |
</threat_model>
