| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-01 | Information disclosure | `ELEVENLABS_*` env | mitigate | Document keys only in `.env`; never log API key or full SDK responses; `.env.example` lists names without values |

</threat_model>
