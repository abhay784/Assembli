<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Next API | Untrusted `contentType` and `sizeBytes` claims |
| Next → S3 | Presigned URL is capability for limited time |
| Next → Redis | Job metadata only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05-01 | T | Client forges S3 key path | mitigate | Server-only key generation; ignore client-supplied paths |
| T-01-05-02 | I | Presigned URL leakage | mitigate | Short expiry (≤900s); unguessable jobId in key; HTTPS in prod |
| T-01-05-03 | E | Huge declared size / spam jobs | mitigate | Validate `sizeBytes` cap; optional rate limit deferred |
| T-01-05-04 | S | Arbitrary URL upload to attacker bucket | mitigate | Sign only with server `S3_BUCKET`; no client bucket param |
| T-01-05-05 | D | Error responses leak stack | mitigate | Generic message to client; log server-side only |
</threat_model>
